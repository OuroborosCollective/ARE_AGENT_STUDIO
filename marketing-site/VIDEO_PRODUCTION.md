# ARE Agent Studio — launch film brief

## Truth boundary

The film may describe the product loop only as observed action → human correction → evidence-bound record → verified device readback. It must not imply a public dataset, a published APK, a physical-device success count, or autonomous results that are not backed by a completed ledger record.

## Approved 16:9 scene order

1. **Observe** — a visible frame and a human action enter the Signal Control Room.
2. **Human corrects** — a visible correction stays distinct from an agent prediction.
3. **Device readback** — the evidence chain reaches an independently verifiable device readback.
4. **Early access** — show the price rule and privacy boundary without inventing a live count: start at €4.25; add €1 only after each complete set of 15 hash-bound device-readback actions; raw data remains private until publication consent exists.

## Voiceover

Use the generated German premium voice track and keep the following approved wording:

> Du zeigst dem System eine echte Handlung. Es beobachtet das sichtbare Signal, bindet deine Korrektur an einen Beleg und lernt daraus – ohne eine Vorhersage als Wirkung auszugeben.
>
> ARE Agent Studio macht aus menschlichen Demonstrationen nachvollziehbare visuelle Agenten. Jede öffentlich sichtbare Zahl stammt aus einem Ledger, nicht aus einem Versprechen.
>
> Der Einstieg beginnt bei vier Euro fünfundzwanzig. Der Preis steigt erst nach je fünfzehn hashgebundenen Device-Readback-Erfolgen. Rohdaten bleiben privat, bis eine ausdrückliche Veröffentlichung dafür vorliegt.
>
> Teach the visual agent. Keep the proof.
