# ARE presentation artwork

`are-signal-hero.png` is the Signal Control Room identity used by the project, Space Card, Dataset Card, and public-facing surfaces.

It is conceptual artwork only. It does not depict a captured gameplay frame, a real device readback, a policy execution, a benchmark, or a measured dataset result. It must never be used as evidence for any runtime or publication claim.

The release workflow keeps the artwork separate from dataset snapshots. The dataset publisher uploads it only as a Dataset Card presentation asset; it is not a training row or a frame in `dataset_manifest.json`.
