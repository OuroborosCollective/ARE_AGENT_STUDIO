# Import provenance

The initial ARE Agent Studio source was supplied as the archive:

`apexagent-vla---autonomous-mobile-gaming-agent-studio.zip`

SHA-256:

`85e3fff0983089baa638cc87c6bc39b35e3a24621b106a407ffd2b3628f79762`

The public repository history intentionally starts from a sanitized root commit rather than preserving the raw archive as a Git commit. The source archive contained a local environment file with non-public configuration. That file was removed, environment files are ignored, and no original environment values are carried into the publishable Git history.

This provenance hash lets the owner correlate the hardened repository with the supplied source archive without publishing the removed configuration payload.
